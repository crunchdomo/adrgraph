# adrgraph Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Python CLI that builds a knowledge graph of a codebase and its ADRs in embedded LadybugDB and fails CI when code violates an ADR rule.

**Architecture:** Extractors (one per language, tree-sitter based) emit a shared vocabulary of units, symbols, edges and raw imports/references. A resolver turns raw imports and references into graph edges. ADR markdown files with YAML frontmatter become Decision and Rule nodes. Everything loads into one LadybugDB file; rule shapes compile to Cypher that returns violations; `check`, `audit` and `query` run over that database.

**Tech Stack:** Python 3.11+, `ladybug==0.22.1`, `tree-sitter==0.26.0`, `tree-sitter-python==0.25.0`, `tree-sitter-hcl==1.2.0`, `python-frontmatter==1.3.0` (brings PyYAML), `pytest`, `argparse` (stdlib).

**Spec:** `docs/superpowers/specs/2026-11-05-adr-enforcer-design.md`

## Global Constraints

- Package, import name and command are `adrgraph`. MIT licence.
- Python `>=3.11`. Dependencies limited to the five above; nothing else without an ADR.
- Extractors are the only modules that import `tree_sitter*`. Only `adrgraph/graph.py` imports `ladybug`. The rule engine (`rules.py`, `check.py`, `audit.py`) never imports `adrgraph.extractors`. These are enforced by the repo's own ADRs in Task 13.
- The graph file `.adrgraph/graph.lbug` is rebuilt from scratch on every run and is git-ignored. `.adrgraph/baseline.json` is committed.
- Regex values are always passed to Cypher as query parameters, never interpolated into the query string (backslashes break the parser inline).
- Line numbers are 1-based. Unit findings report line 1. Paths are POSIX, relative to the current working directory.
- Exit codes: 0 pass, 1 violations (error severity, outside baseline) or failing audit checks, 2 tool error.
- Text finding format, exactly: severity left-padded to 9 characters, one space, then `<path>:<line>  <decision>/<rule>  <message>` with two spaces between the remaining fields.

## Review Focus

1. A source file with syntax errors: tree-sitter yields `ERROR` nodes. The file still produces a Unit and whatever symbols parsed; nothing crashes. Test in Task 6.
2. A non-ADR markdown file in the ADR directory (a `README.md`, a template without `id`): skipped silently, never a tool error. Test in Task 2.
3. An import cycle under a transitive rule: the variable-length path is bounded (`*1..10`), the check terminates and reports each violator once. Test in Task 5.
4. A rule with an unknown `via` label or unknown selector key: exit 2 with a message naming the decision and rule, not a Cypher stack trace. Tests in Task 4 and Task 5.
5. A rule whose selector matches nothing: `check` reports no violation, metrics report compliance as not applicable, and `audit` flags it as orphan. Tests in Task 9 and Task 11.

### Task 2: ADR loader

**Files:**
- Create: `adrgraph/adr.py`, `tests/fixtures/adr/0001-gateway.md`, `tests/fixtures/adr/0002-proposed.md`, `tests/fixtures/adr/README.md`
- Test: `tests/test_adr.py`

**Interfaces:**
- Produces:
  - `class AdrError(Exception)` whose message includes the file path.
  - `@dataclass Rule(id: str, decision: str, shape: str, spec: dict, severity: str, description: str)` where `shape` in `{"only", "never", "must", "cypher"}` and `spec` is the value under that key (a dict for shapes, a string for cypher).
  - `@dataclass Decision(id: str, title: str, status: str, owner: str, date: str, review_date: str | None, supersedes: list[str], path: str, rules: list[Rule])` with `status` in `STATUSES = {"proposed", "accepted", "superseded", "deprecated"}`.
  - `load_adrs(dirs: list[str]) -> list[Decision]` sorted by id. Reads every `*.md` in each dir (not recursive). A file whose frontmatter lacks `id` is skipped. Raises `AdrError` on: missing `title` or `status`; status outside `STATUSES`; a rule with zero or more than one of `only|never|must|cypher`; a rule without `id`; `severity` outside `{"error", "warn"}`; duplicate decision ids across all dirs; duplicate rule ids within a decision. Missing `severity` defaults to `"error"`. Dates are stringified with `str()` (PyYAML parses them as `date`). Missing `supersedes` is `[]`, missing `review_date` is `None`, missing `owner` is `""`.

### Task 3: Graph store

**Files:**
- Create: `adrgraph/graph.py`
- Test: `tests/test_graph.py`

**Interfaces:**
- Consumes: `model.Unit`, `model.Symbol`, `model.Edge`, `adr.Decision`, `adr.Rule`.
- Produces:
  - `class Graph` with `__init__(self, path: str)` that deletes any existing file at `path` (and `path + ".wal"` if present), creates parent dirs, opens `ladybug.Database(path)` and one `ladybug.Connection`, and runs the DDL.
  - `Graph.load(self, units: list[Unit], symbols: list[Symbol], decisions: list[Decision], edges: list[Edge], binds: list[tuple[str, str]] = ()) -> None`. Rules come from `decision.rules`. `binds` are `(rule_key, node_id)` pairs where `rule_key = f"{decision.id}/{rule.id}"`.
  - `Graph.query(self, cypher: str, params: dict | None = None) -> list[dict]` returning one dict per row keyed by column name.
  - `Graph.close(self) -> None`. Also a context manager.
  - `Graph.count(self, label: str) -> int`.
- DDL, exactly these tables:
  - `Unit(id STRING, path STRING, name STRING, lang STRING, kind STRING, line INT64, PRIMARY KEY(id))`, `line` always 1.
  - `Symbol(id STRING, name STRING, qualified STRING, kind STRING, lang STRING, path STRING, line INT64, end_line INT64, ast_kind STRING, PRIMARY KEY(id))`
  - `Decision(id STRING, title STRING, status STRING, owner STRING, date STRING, review_date STRING, path STRING, PRIMARY KEY(id))`
  - `Rule(id STRING, decision STRING, rule_id STRING, shape STRING, cypher STRING, severity STRING, description STRING, PRIMARY KEY(id))` where `id` is the rule key `ADR-0001/gateway-only-via-contracts`, `cypher` is the compiled query (empty string at load time; Task 9 fills it only in memory, not in the graph).
  - `CONTAINS(FROM Unit TO Unit, FROM Unit TO Symbol, FROM Symbol TO Symbol)`, `IMPORTS(FROM Unit TO Unit)`, `CALLS(FROM Symbol TO Symbol, FROM Unit TO Symbol)`, `REFERENCES(FROM Symbol TO Symbol, FROM Symbol TO Unit, FROM Unit TO Symbol, FROM Unit TO Unit)`, `HAS_RULE(FROM Decision TO Rule)`, `SUPERSEDES(FROM Decision TO Decision)`, `BINDS(FROM Rule TO Unit, FROM Rule TO Symbol)`.
- Loading uses `UNWIND $rows AS r CREATE (...)` per node table, and per `(label, src_table, dst_table)` group for edges: `UNWIND $e AS e MATCH (a:Src {id: e.a}), (b:Dst {id: e.b}) CREATE (a)-[:LABEL]->(b)`. Edges whose endpoint ids are not loaded nodes are dropped with no error. `SUPERSEDES` edges whose target decision does not exist are dropped (audit reports it).

### Task 4: Selectors

**Files:**
- Create: `adrgraph/selectors.py`
- Test: `tests/test_selectors.py`

**Interfaces:**
- Produces:
  - `class SelectorError(ValueError)`.
  - `glob_to_regex(glob: str) -> str`: anchored (`^...$`), `**` matches any characters including `/`, `*` matches `[^/]*`, `?` matches `[^/]`, everything else escaped. `**/` at the start also matches the empty prefix (so `**/x.py` matches `x.py`).
  - `compile_selector(sel: dict, var: str, prefix: str) -> tuple[str, dict]`: returns a Cypher boolean expression over node variable `var` and the params it needs. Params are named `{prefix}_path`, `{prefix}_name`, `{prefix}_kind`, `{prefix}_lang`, each present only if the key is. Allowed keys: `path`, `kind`, `name`, `lang`; any other key raises `SelectorError` naming the key. Empty selector compiles to `true`.
  - Semantics: `kind: unit` → `label({var}) = 'Unit'`; any `kind` in `SYMBOL_KINDS` → `label({var}) = 'Symbol' AND {var}.kind = ${prefix}_kind`; other kind → `SelectorError`. `name` → `(label({var}) = 'Unit' AND {var}.name =~ $p) OR (label({var}) = 'Symbol' AND ({var}.name =~ $p OR {var}.qualified =~ $p))`. `path` → `{var}.path =~ ${prefix}_path`. `lang` → `{var}.lang = ${prefix}_lang`. Fragments joined with `AND`, each parenthesised.

### Task 5: Rule compilation and evaluation

**Files:**
- Create: `adrgraph/rules.py`
- Test: `tests/test_rules.py`

**Interfaces:**
- Consumes: `selectors.compile_selector`, `graph.Graph`, `adr.Rule`.
- Produces:
  - `class RuleError(ValueError)` with message starting `"{decision}/{rule_id}: "`.
  - `@dataclass(frozen=True) Violation(decision: str, rule: str, node_id: str, path: str, line: int, message: str)`.
  - `compile_rule(rule: Rule) -> tuple[str, dict]`: the Cypher and params. Raw `cypher` shape returns `(rule.spec, {})`.
  - `evaluate(graph: Graph, rule: Rule) -> list[Violation]` sorted by `(path, line, node_id)`, de-duplicated by `node_id`. Rows must have `node_id`, `path`, `line`, `message`; a raw cypher rule whose rows lack any of these raises `RuleError`.
  - `bound_selector(rule: Rule) -> dict | None`: the selector whose matches count as "bound" for metrics and BINDS: `from` for `never`, `to` for `only`, `every` for `must`, `None` for `cypher`.
  - `MAX_HOPS = 10`.
- Validation in `compile_rule`: required keys per shape (`only`/`never`: `from`, `to`, `via`; `must`: `every`, `has`, `via`); `via` is a string or list of strings, each in `model.EDGE_LABELS`; `transitive` only on `only`/`never`; `direction` only on `must`, in `{"out", "in"}`; any unknown key or `SelectorError` → `RuleError`.
- Compiled shapes (selector params use prefixes `f`, `t`, `e`, `h`, `n`; `VIA` is `A|B` joined labels):
  - never, direct: `MATCH (a)-[:VIA]->(b) WHERE (<f(a)>) AND (<t(b)>) RETURN DISTINCT a.id AS node_id, a.path AS path, a.line AS line, 'reaches ' + b.id AS message`
  - never, transitive: same with `-[:VIA*1..10]->`.
  - only, direct: `MATCH (a)-[:VIA]->(b) WHERE NOT (<f(a)>) AND (<t(b)>) RETURN ...`
  - only, transitive: `MATCH (a)-[:VIA*1..10 (r, n | WHERE NOT (<f(n)>))]->(b) WHERE NOT (<f(a)>) AND (<t(b)>) RETURN ...`
  - must, out: `MATCH (e) WHERE (<e(e)>) AND NOT EXISTS { MATCH (e)-[:VIA]->(h) WHERE (<h(h)>) } RETURN e.id AS node_id, e.path AS path, e.line AS line, 'has no VIA edge to a matching node' AS message`; `in` flips the arrow.

  - Walk each root with `os.walk`, pruning directory names in `excludes` and any glob in `excludes` matched against the path relative to cwd; skip symlinks. Package units get `CONTAINS` edges to their direct child modules and subpackages by name prefix.
  - Reference resolution, per `RawRef`: split `name` on the first `.`; if the head is in the unit's alias map, replace it with the absolute dotted; else qualify with the unit's own module name (`f` in module `a` → `a.f`, `self.go` is left as written). Look up the result in `symbols_by_qualified`; found → `CALLS` (when `call`) or `REFERENCES` edge from `src_id` to the symbol. Not found → `CALLS`/`REFERENCES` to a `Symbol(id=unresolved_id(name), name=name, qualified=name, kind="unresolved", lang=<lang>, path="", line=0, end_line=0, ast_kind="")`, created once per name.

**Files:**

**Interfaces:**
- Consumes: `rules.evaluate`, `rules.bound_selector`, `selectors.compile_selector`, `graph.Graph`, `adr.Decision`.

  - `@dataclass(frozen=True) Finding(severity: str, decision: str, rule: str, node_id: str, path: str, line: int, message: str)` with `severity` in `{"error", "warn", "baselined", "fixed"}`.

  - `@dataclass Metrics(per_rule: dict[str, RuleMetrics], per_adr: dict[str, float | None], overall: float | None, fixed: int, new: int)` where keys of `per_rule` are rule keys `ADR/rule`, compliance is `1 - violations / bound` summed over rules with a non-None bound, `None` when no rule has bound nodes.

Findings are sorted by `(path, line, decision, rule, node_id)`.

### Task 10: Audit

**Files:**
- Create: `adrgraph/audit.py`
- Test: `tests/test_audit.py`

**Interfaces:**
- Consumes: `check.bind`, `rules.evaluate`, `graph.Graph`, `adr.Decision`.
- Produces:
  - `@dataclass(frozen=True) AuditFinding(check: str, severity: str, decision: str, rule: str, message: str)` with `check` in `{"orphan", "stale", "dangling", "overdue", "contradiction"}` and `severity` in `{"error", "warn"}`.
  - `run_audit(graph: Graph, decisions: list[Decision], today: datetime.date, strict: bool = False) -> list[AuditFinding]` sorted by `(decision, rule, check)`.
- Findings use `decision.id` from the enclosing `Decision`, never `rule.decision`.
- Severity: `dangling` and `contradiction` are `error`; `orphan`, `stale`, `overdue` are `warn`, or `error` when `strict`. (Duplicate ids are raised by `load_adrs` before audit runs.)
- Checks:
  - orphan: an accepted (or proposed) shape rule where any of its selectors (`from`/`to`/`every`/`has`) matches zero nodes. Message names the selector key.
  - stale: a rule on a `superseded` or `deprecated` decision with `evaluate(...)` non-empty. Message includes the violation count.
  - dangling: `supersedes` id not among decisions, or target decision whose status is `accepted`.
  - overdue: accepted decision with `review_date < today`.
  - contradiction: for each accepted `must` M and each accepted `never` N or `only` O sharing at least one `via` label: let `E`, `H` be M's bound sets (H oriented by M's `direction`: for `in`, swap the roles so `H` is the set that must have an edge *to* `E`). For each `e` in `E`: forbidden = N's `to` set if `e` in N's `from`; or O's `to` set if `e` not in O's `from`. If `H` is non-empty and `H ⊆ forbidden`, report one finding on M naming the other rule. Bound sets come from `compile_selector` queries returning ids.

import datetime
from adrgraph.adr import Decision, Rule
from adrgraph.audit import run_audit

def dec(id, status, rules, supersedes=(), review=None):

TODAY = datetime.date(2026, 11, 5)

    assert all(f.severity == "warn" for f in fs)

**Interfaces:**

- Produces: `main(argv: list[str] | None = None) -> int` and `build(adr_dirs, src_roots, excludes, db_path) -> tuple[Graph, list[Decision], list[str]]` (graph, decisions, warnings), which scans, loads ADRs, loads the graph including `BINDS` edges from `check.bind`.
- Arguments (argparse, subcommands `build`, `check`, `audit`, `query`):
  - shared: `--adr` (append, default `["docs/adr"]`), `--src` (append, default `["."]`), `--exclude` (append, added to `DEFAULT_EXCLUDES`), `--db` (default `.adrgraph/graph.lbug`).
  - `check`: `--format {text,json}` (default text), `--baseline` (default `.adrgraph/baseline.json`), `--write-baseline` (flag).
  - `audit`: `--format`, `--strict`.
  - `query`: positional `cypher`; uses the existing db without rebuilding; prints rows as tab-separated with a header line, or JSON with `--format json`.
- Output:
  - Warnings from scan go to stderr prefixed `warning: `.
  - `check` text: one line per finding, `f"{severity:<9} {path}:{line}  {decision}/{rule}  {message}"` where severity is left-padded to 9 characters (so fields stay two-space separated); then a blank line and the metrics: `overall compliance: 87.5%` (or `n/a`), one line per ADR `ADR-0001: 50.0% (2 rules, 1 violation)`, then `baseline: 1 fixed, 2 new`. JSON: `{"findings": [...], "metrics": {"overall": 0.875, "per_adr": {...}, "per_rule": {...}, "fixed": 1, "new": 2}, "failed": true}`.
  - `audit` text: `f"{severity:<9} {check:<13} {decision}/{rule}  {message}"` per finding; JSON list.
  - `--write-baseline` writes `current` to the baseline path, prints `wrote <path> (<n> violations)`, and exits 0.
- Exit codes: `check` 1 when `failed`; `audit` 1 when any finding has severity `error`; 2 on `AdrError`, `RuleError`, `SelectorError`, or a query/Cypher exception, printing `error: <message>` to stderr; 0 otherwise.
